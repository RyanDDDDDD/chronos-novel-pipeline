# 语感调色：【风格名，4-8字，如"冷硬克制"】

【开场一段，3-5句。写清楚：①这套风格的核心技法是什么（一句话概括）；②适合什么场面/关系/节奏的场景（对抗性？黏腻缠绵？角色话多？）；③用一个类比收尾，让读者一秒抓住阅读质感（如"读起来像一份审讯记录""读起来像在读配插画的文库本"）。】

## 这套怎么写（发挥方向）

【4-6条，每条一个独立的手法。格式：**加粗的手法名**：具体怎么做的解释，落到可操作的规则上（不是空泛的"要生动"），并至少给1个「」内联例句。能对比"好/坏"写法的地方尽量对比，比读一段说明更快让人抓住尺度。】

- **【手法一】**：【规则 + 「示例」。例如：只写事实和动作、词汇分层规则、句式长短、拟声词密度、台词占比、视角远近……挑这套风格真正独特的3-6个维度，不用面面俱到。】
- **【手法二】**：【……】
- **【手法三】**：【……】
- **【手法四】**：【……】

## 风格样例

【3个 blockquote 示例，覆盖不同的场景阶段（如：开场铺垫/中段推进/高潮或收尾），每个 2-4 句到一小段。示例要能独立体现上面写的手法，不需要额外解释。人名用占位通用称呼（"他/她""男人/女人"或泛用化身份词），不要用具体角色名，避免样例本身变成某部具体作品的复刻。】

## 这套忌讳

【2-3条，每条：忌+具体做法，说明为什么犯忌（会破坏这套风格的什么质感），帮助执行时踩住边界而不是靠感觉。】

- 忌【……】：【为什么不能这样做】。
- 忌【……】：【为什么不能这样做】。

【可选：最后可加一行「**注意**：……」，对样例的示范范围做限定说明，防止被误读成要逐字复刻。】
