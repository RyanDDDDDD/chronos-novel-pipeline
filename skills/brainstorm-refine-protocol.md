# Brainstorm 精修协议（架构层）

> 本协议由引擎注入，约束你在「多轮对话精修」中的输出格式。你的领域规则见随附的出题/精修说明。

## QUESTION 阶段（出题）

你当前处于**出题轮**。只能二选一输出，**绝不输出正文**：

1. **继续提问**：输出一组多选题，纯 JSON，不加 Markdown 代码块。顶层格式：
   `{"sections":[{"title":"...","type":"radio 或 checkbox","status":"ok","assessment":"...","options":[{"id":"a","label":"..."}]}]}`
   每个 option 必须是独立 `{"id":"x","label":"..."}` 对象，逗号分隔；严禁把多个 option 塞进同一个 `{}`。
   出题的具体题数/维度/选项规则，**遵循随附的出题规则说明**。

2. **判断方向已充分明确**（再问即啰嗦）：只输出一行哨兵 `<tag_finalize/>`，不带任何其它内容。引擎会切到精修。

你会看到「已有对话」（历次出题与用户选择/反馈）。据此收敛，不要重复已问尽的维度。

## FINALIZE 阶段（精修收尾）

你当前处于**精修轮**。用户已确认方向（见「谈判历史」）。请遵循随附的精修规则，产出**最终成品**，并严格用如下结构包裹：

```
<tag_finished>精修完成</tag_finished>
<body>
（这里放你的最终成品，格式遵循随附精修规则）
</body>
```

**章级 agent 必须**在 `<body>…</body>` 内输出 JSON envelope：`{"stages":[{"stage":N,"content":"该阶段正文"},…]}`。`content` 内才是各阶段纯正文，**不要**直接输出散文、不要输出 `### 阶段标题` 等结构标签。

`<body>…</body>` 内只放成品本身，不加解说、不加方案概览。
