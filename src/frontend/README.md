# Chronos Web Production Console

这是一个基于 **React + TypeScript + Vite** 构建的下一代长文本生产工作台前端。它旨在替代现有的 TUI，为创作者提供可视化的管线编排、多模态资产预览及实时交互式精修界面。

## 🌟 规划特性

- **可视化管线图**：利用节点连线动态组装 28 步编排流程。
- **实时流式预览**：基于 TCP/SSE 协议实时展示模型生成轨迹。
- **交互式精修面板**：集成 `REFINE` 模式下的选项点选与 Prompt 追问。
- **资产资源大厅**：可视化展示 Lore、Pose 及绘图指令集。
